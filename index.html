What is Minimum Spanning Tree?

A Minimum Spanning Tree is a subset of the edges of a connected weighted graph that connects all vertices without forming cycles and has the minimum possible total edge weight.


IN THIS PROJECT I AM USING Prim's Algorithm and Kruskal's Algorithm to find the Minimum Spanning Tree of the campus network graph. I USED OUR COLLAGE SANDIP UNIVERSITY CAMPUS MAP TO DESIGN THE GRAPH AND FIND THE MINIMUM COST NETWORK CONNECTION.

Kruskal's Algorithm

Kruskal's algorithm sorts all edges according to their weight and repeatedly selects the smallest edge that does not create a cycle.


Steps:
  1. Sort all edges by increasing cost.
  2. Select the cheapest edge.
  3. Check whether it creates a cycle.
  4. If there is no cycle, add it to MST.
  5. Continue until all buildings are connected.

Prim's Algorithm

Prim's algorithm starts from one building and repeatedly selects the cheapest edge that connects the existing tree to a new building.


Steps:
  1. Choose a starting building.
  2. Find the cheapest connecting edge.
  3. Add the new building.
  4. Repeat until all buildings are connected.
